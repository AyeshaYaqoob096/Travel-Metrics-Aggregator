## Passing Objects as Function Parameters

## 📌 Short Description
This project demonstrates the core concepts of Object-Oriented Programming (OOP) in C++, focusing specifically on class declarations, managing data members, writing member functions, and passing entire objects as arguments to member functions. 

The program models a `Travel` tracker that captures travel metrics (kilometers and hours) for different trips and aggregates them by processing a secondary object passed by value.



## 🛠️ Features
* **Encapsulation:** Uses private data members (`km`, `hr`) to protect internal data states.
* **Constructors & Destructors:** Initializes data attributes safely and handles object life cycles cleanly.
* **Object Interactions:** Features an `Add(Travel p)` function demonstrating how objects interact with other instances of the same class type.
